# Scoped prose polish

Use ieee_guidance/get_writing_guidance with workflow=language_polish, operation=polish/audit, stage=start/check. Select language=en/zh/bilingual from the actual requested text; choose register=academic for scholarly/IEEE prose, general for other prose, respecting an explicit user preference. Do not send section/module. Do not browse the private library or substitute local core skills.

The user's own account model reads and revises only authorized necessary text/files. The service returns selected original guidance, not model output. Requests contain routing selectors only; no text, local paths, BibTeX or data upload. Preserve the user's requested paragraph/file/output scope. An audit identifies observed issues; a polish returns the requested revision or edited artifact. Do not require a full-text output, whole-paper rewrite or structural reorganization for a scoped language task. This route is prose editing, not proof that an author used AI.

Retrieve start guidance, retain the returned library_release for subsequent calls, apply it, then retrieve check guidance after material changes/audit as appropriate. needs default false: examples only when concrete language-specific before/after examples help; notation/formulas for actual changed math or definitions; registry only for an existing applicable registry. Academic mode includes its shared dependencies. Missing material remains pending; do not start reference checks, file uploads or figure generation after polishing without an explicit separate user request.

Use the returned guidance priorities and task scope during editing; check the actual resulting text rather than merely noting successful retrieval. Honor the requested language/register and preserve facts, certainty, equations, labels, citations and environments. Keep execution status separate from the author prose. Explain unresolved evidence/available-tool limits in the task report when relevant; do not add an unrelated negative paragraph to the author's progress description.

Require API contract ieee-guidance-v1 and available capability language_polish, regardless of minor version number. An old pinned library lacking this capability is an error; explicitly start a new task with an available release, never silently mix versions. Unknown contract, unavailable guidance or sustained transport error stops the route. One retry is allowed for a temporary transport/5xx failure; pause/report429, no auth retry. Do not save returned guidance as a core skill or print the private rule inventory.

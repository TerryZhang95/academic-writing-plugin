# Explicit reference and figure tasks

Use only when the user explicitly requests this cloud reference check or figure generation with the necessary files. This action uploads the selected tex/bib/csv content to the service; ordinary writing guidance continues sending routing fields only. Server inputs/cache are deleted on completion, outputs expire within ten minutes (cleanup runs every five seconds). Do not upload any other manuscript, home/project tree, credential, hidden file, Zotero database or uploaded executable code. Reading a local file alone is not upload permission. If the selected file/upload scope is unclear, clarify that scope first.

Resolve the installed public helper from this skill directory: ../../scripts/bridge.py. Run with the user's local Python3; it needs no packages/model API key. The user's account model interprets the report. The cloud executes only fixed data tools. Use absolute helper/root paths, quote arguments safely and never build shell code from manuscript content. No pipeline or arbitrary uploaded Python/shell execution.

Reference task: `python3 <helper> references --root <authorized-task-directory> --files paper.tex refs.bib --output reference-check`. Files are explicitly listed relative to root: one ordinary .bib and at most four needed .tex files; no automatic include/input traversal. Add `--external` only for authorized public Crossref DOI identity checks. No DOI means pending; no title-search guessing. Files together are limited to 256 KB and the batched library to 100 entries (external requests at most20 per task). Supply a fresh output directory. Read references.json and references.md, report missing/duplicate citation keys, field issues and identity-match status separately. DOI identity and a title do not prove support for a cited claim. PDF source-text verification and Zotero access are not performed by this executor; report them pending or use separately authorized available client tools, without claiming the executor checked them. Custom BibTeX/citation macros may need an ordinary export or manual review.

Plot task: `python3 <helper> plot --root <authorized-task-directory> --files data.csv --kind line --xlabel <label> --ylabel <label> --output figure-output`. `--kind bar` selects grouped bars; `--columns 1` or `2`; optional `--title`. CSV header is x/category followed by one to six series. Line x values must be finite and strictly increasing; values are finite numbers. Bars allow at most 24 categories. At most 2000 rows. Validate task intent, units, data meaning, labels and appropriate line/bar selection with author material before invoking; do not invent missing values or run simulation/fitting. This is quantitative rendering, not arbitrary/conceptual figure generation. It returns figure.png, figure.pdf and a figure.json record. Inspect output as available and report readability/units unresolved if not checked; task success does not establish scientific validity.

The bridge discovers the latest explicit execution-capable library and pins the task. To continue a task's specified release use `--library-release <returned-version>`; unavailable historical execution capability is an error, never silent fallback. The helper performs upload/poll/download and saves outputs to a new directory inside the authorized task root; never make users copy guidance or task credentials. Service busy/429 means pause and retry later, not retry flooding. Missing Python, network failure, invalid data, expiry or deadline: stop the affected task and explain the concrete missing dependency; don't pretend files were produced. Do not print or persist task_secret, request headers or server guidance.

Reference checks keep the full selected .bib/.tex intact. The public bridge automatically checks global citation consistency and runs sequential external batches of up to20 entries, at most100 entries total. external=false performs one complete local check without Crossref requests. Macro/inheritance/concatenation BibTeX formats require manual review rather than partial parsing. Reports identify each entry by stable ordinal including duplicate keys, preserve checked results and mark unavailable/pending entries if a later batch fails or is rate limited. Never treat paused external checks as verified. No auto-external check after writing. Use a library declaring audit_batched; older pins cannot silently switch. General quantitative user-side plots from authorized arrays/CSV/TSV/JSON/Excel use workflow=results, operation=figure_render; this fixed cloud executor remains CSV line/bar only.
